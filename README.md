# FocusFlow - 智慧工作追蹤與代辦排程系統

專為高效工作者打造的全方位進度追蹤與語音智慧排程系統，依據工作特性劃分為三大核心模組：

---

## 🌟 核心工作象限

### A. 靜態工作 (Static Deliverables)
- **涵蓋範疇**：完成報告、簡報設計、資料分析、系統測試及各類自訂工作。
- **功能特點**：
  - **4 階看板管理**：待處理 (Pending) ➔ 進行中 (In Progress) ➔ 審查/測試 (Review) ➔ 已完成 (Completed)。
  - **類別動態管理 (NEW)**：可自由新增、修改名稱/色彩、刪除類別標籤（內建保護將關聯任務安全過渡至「其他」）。
  - **卡片即時滑桿調整進度 (NEW)**：在看板卡片上直接拖拉進度 Bar，放開即刻自動保存，免開編輯視窗。進度達 100% 時自動標記完成。
  - **時間回推建議進度 Bar (NEW)**：系統根據任務建立日期與截止日期（Due Date），自動線性推算「當前應有進度」，並即時標示**進度超前 (+X%)** 或 **進度落後 (-X%)**。
  - **子任務檢核清單 (Checklist)**：細化階段交付步驟。

### B. 創意發想 (Idea Sparks & Incubation)
- **涵蓋範疇**：細節不明確的靈光乍現、新構想、實驗性提案。
- **功能特點**：
  - **極速捕捉**：隨手輸入或記錄，支援自選色彩與標籤管理。
  - **星號精選篩選 (NEW)**：一鍵切換「全部靈感」與「⭐ 星號精選」，快速回顧核心想法。
  - **編輯與追加補充 (NEW)**：點擊「📝 編輯/補充」，除了能修改主體外，還能一鍵**快速追加帶時間戳的補充筆記**（如 `[2026-10-27 17:05 補充筆記]`）。
  - **🚀 一鍵晉升任務**：當構想成熟時，可「一鍵轉化」為 A 類靜態工作並排定 Deadline。

### C. 業務會談與語音排程 (Business Voice & Calendar)
- **涵蓋範疇**：外部客戶洽談、商務通話、會議對談。
- **功能特點**：
  - **語音轉文字 (Speech-to-Text)**：瀏覽器原生語音辨識（支援台灣中文/英文，低延遲免 API Key）。
  - **AI 重點摘要**：自動提煉會議要點與 Action Items 行動待辦。
  - **關鍵時序解析 (Temporal Entity Extraction)**：精準辨識如「明天下午三點」、「下週三早上十點」、「11月15日」等口語時間。
  - **Google Calendar 深度整合**：
    - 一鍵開啟官方 Google Calendar 預填頁面建立排程與提醒。
    - 支援標準 `.ics` (iCalendar) 檔案下載。

## 🚀 快速啟動

### 1. 執行啟動腳本
```bash
./run.sh
```
或直接執行：
```bash
python3 app.py
```

### 2. 開啟瀏覽器
開啟瀏覽器前往：
👉 **http://localhost:8080**

即可開始使用視覺化儀表板、語音錄音與任務看板！

---

## 🛠️ 技術架構
- **後端**：Python 3 (REST API 輕量伺服器，整合 `libsql_client`、`re`、`json`)。
- **前端**：響應式 Web 應用程式 (HTML5 + Tailwind CSS + Web Audio / Web Speech API)。
- **資料庫**：**Turso Cloud DB (LibSQL)** 雲端分散式資料庫，支援跨裝置即時同步與雲端高可用性（亦支援環境變數 `.env` 配置）。
- **排程協定**：Google Calendar Template URL Protocol + iCalendar RFC 5545。
